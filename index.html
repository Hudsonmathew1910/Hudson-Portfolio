Flagship AI Assistant Platform

Hero's AI

One AI assistant that picks the right brain for every question.

Overview

Hero's AI is a live, production-grade AI assistant platform built with Django. Users can type or speak requests, and the system intelligently detects the context and intent, routing each query to the best-suited model and handler with zero dead-ends.

Production Interface & Architecture Previews

Primary Assistant Workspace
Multi-Model Routing View
Integrated Tool Execution

The Problem

Most AI chatbots rely on a single large language model. If that API times out, suffers an outage, or hits rate limits, the entire application breaks. Furthermore, treating every user request identically (whether it's code generation, math, a live web search, or file inspection) leads to bloated costs and suboptimal answers.

What I Built & Architecture

  • Baymax Dispatcher: An orchestration engine managing automated fallback across Gemini → OpenRouter → Groq, ensuring high availability.
  • NLP Intent Router: Classifies user queries across 8 distinct intent domains (coding, web search, file analysis, creative, math, etc.) before making LLM calls to optimize token budgets.
  • Fast Mode (Concurrent Racing): Leverages Python's ThreadPoolExecutor to race two models concurrently, instantly returning whichever yields the first token for 50–75% lower latency.
  • Interruptible Voice Mode: Live speech synthesis with automatic pause/interruption as soon as the user speaks.
  • Zeno Browser Extension: Manifest V3 Chrome/Edge extension providing right-click "Ask Zeno" context sync to the user's primary chat history.
  • Multimodal Tools: DuckDuckGo & Wikipedia search synthesis, OCR document extraction via pytesseract, and Google OAuth / email auth.

Security & Reliability

User API keys are encrypted at rest using Fernet symmetric encryption and never exposed to the client. The system implements strict CSRF protection, secure HTTP-only sessions, rate limiting, and request payload validation.

Tech Stack

Django 5.2 Python 3.11 PostgreSQL (Neon) Pinecone Google Gemini OpenRouter Groq Gunicorn WhiteNoise

What I Learned

Designed fault-tolerant multi-model fallback topologies so no individual API downtime can crash user sessions; demonstrated why pre-LLM intent classification cuts inference costs while enhancing precision; and mastered production deployment, session management, and credential encryption.

Zero-Code RAG & Data Analytics

Infinsight

Upload your data. Ask questions in plain English.

Overview

Infinsight is the autonomous data analyst engine integrated into Hero's AI. It empowers non-technical users to query complex spreadsheets, CSVs, and PDF files using plain conversational language without writing SQL or Python.

Pipeline & Analytical Views

Natural Language Q&A Interface
Sandboxed Pandas Analytics & Plots

The Problem

Valuable business insights remain trapped inside raw tables and lengthy PDFs. Most team members lack the scripting skills to compute aggregations, correlations, or cohort breakdowns, forcing them to guess or wait on technical analysts.

How It Works (Pipeline)

  1. Document Ingestion: Files (CSV, Excel, PDF) are parsed and segmented into semantic chunks (row-level summaries for tables, page blocks for documents).
  2. Vector Embeddings: Chunk vectors are computed using gemini-embedding-001 and indexed into Pinecone vector databases under dedicated user namespaces.
  3. Semantic Search: When a user asks a question, top-k relevant context chunks and schema metadata are retrieved.
  4. Sandboxed Code Execution: For quantitative queries, dynamic Pandas code is synthesized and executed in an isolated, secure asteval sandbox to generate analyst-grade figures, trends, and summaries.

Supported Analytics

  • RFM Analysis: Recency, Frequency, and Monetary customer segmentation.
  • Time-Series Trends: Aggregated rolling averages, seasonality, and period-over-period comparisons.
  • Forecasting: Linear regression trends and forward-looking projections.
  • Unified Q&A: Natural language questions answered across tabular sheets and unformatted PDF text.

Tech Stack

Python Pandas Pinecone Gemini Embeddings asteval Sandbox Django Vector Search

What I Learned

Deepened understanding of production RAG workflows (chunking strategies, similarity scoring, and context injection); learned the security imperative of executing generated code inside AST sandboxes rather than raw eval(); and turned technical AI pipelines into approachable features for non-technical users.

Kaggle Machine Learning

Spaceship Titanic

A machine learning pipeline combining multiple models for one stronger prediction.

Overview

A competitive Kaggle binary classification project predicting whether passengers were transported to an alternate dimension following a spacetime collision. It emphasizes meticulous exploratory data analysis, domain feature engineering, and a weighted ensemble.

Modeling & Ensemble Architecture

Exploratory Analysis, Decomposition & Weighted Blending Pipeline

End-to-End ML Workflow

  • Exploratory Data Analysis: Inspected feature correlations, class balance, and missing value distributions across amenities and demographic data.
  • Targeted Data Cleaning: Handled missing entries via correlation-driven imputation, medians, or strategic drops per column.
  • Feature Engineering: Decomposed the compound Cabin feature into Deck, Number, and Side, unlocking rich predictive signals.
  • Encoding & Normalization: Applied One-Hot Encoding for categorical features and StandardScaler normalization for numerical expenditure figures.

Why a Weighted Ensemble?

Individual algorithms make different prediction errors. Rather than relying on a single classifier, predictions from 8 diverse architectures (Logistic Regression, Random Forest, XGBoost, CatBoost, AdaBoost, KNN, Decision Tree, and a 3-layer Deep Neural Network) were combined via tuned ensemble weights to stabilize variance and maximize generalization accuracy.

Tech Stack

Python Pandas NumPy scikit-learn TensorFlow / Keras XGBoost CatBoost Jupyter

What I Learned

Careful feature engineering often yields higher gains than mere model tuning; gained practical experience observing how diverse tree algorithms versus neural networks respond to tabular distributions; and learned to diagnose confusion matrices and F1 scores rather than raw accuracy alone.

EpicOutlet

An online store with an AI shopping assistant built in.

Overview

A full-stack e-commerce marketplace built with Django 5.2 that marries traditional digital storefront workflows (multi-category catalogs, cart, favourites, and a Jazzmin-styled back-office) with Shop-Bot—an AI conversational shopping assistant.

Store Capabilities & REST API

  • Broad Categories: Mobile, Fashion, Electronics, Home, and Grocery collections.
  • Shopper Experience: Persistent shopping cart, favourites wishlist, and user account management.
  • REST API: Endpoints exposed under /api/v1/ via django-tastypie for products, categories, cart, and favourites.
  • Modern Admin: Jazzmin-themed management portal for inventory tracking, orders, and assets.

Shop-Bot: The AI Shopping Assistant

Shop-Bot uses an OpenAI-compatible SDK powered by the Groq API (GPT-OSS 120B) with native tool-calling (function calling). Instead of guessing product availability or fabricating prices, the model triggers a search_products function that queries the live PostgreSQL database filtering by category, price ceiling, vendor, or trending metrics.

It maintains a 12-message conversational memory window so multi-turn chats feel natural, rendering responses in cleanly parsed markdown.

Tech Stack

Django 5.2 PostgreSQL (Supabase) django-tastypie Groq API Tool-Calling Cloudinary Bootstrap 5.3 Gunicorn Render

What I Learned

How tool-calling enables language models to bridge LLM reasoning with live relational databases; how to design clean Django MVT coupled with Tastypie REST APIs; and how to manage Cloudinary cloud media storage, environment variables, and production deployment on Render.
